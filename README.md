
# UniGuide

UniGuide — веб-сервис для поиска университетских активностей и формирования персональных рекомендаций на основе интересов студентов.

## Возможности

- Регистрация и авторизация пользователей
- Выбор и сохранение интересов
- Персональные рекомендации
- Каталог активностей с фильтрацией по категориям
- Просмотр подробной информации об активностях
- Добавление и удаление избранного

## Технологии

- Frontend: React, JavaScript, Vite
- Backend: Python, FastAPI, SQLAlchemy
- База данных: PostgreSQL 17
- Авторизация: JWT
- Контроль версий: Git

## Требования

Для локального запуска необходимы:

- Python 3.11 или выше
- Node.js 22 или выше
- PostgreSQL 17
- npm

## Установка и запуск

Все команды выполняются из корневой папки UniGuide, если не указано иное.

### 1. Создание базы данных

Создайте в PostgreSQL базу данных:

`uniguide_db`

### 2. Настройка окружения

Создайте файл `.env` в корне проекта:

```dotenv
DB_HOST=localhost
DB_PORT=5432
DB_NAME=uniguide_db
DB_USER=postgres
DB_PASSWORD=YOUR_PASSWORD

JWT_SECRET_KEY=YOUR_RANDOM_SECRET_KEY
JWT_ALGORITHM=HS256
JWT_EXPIRE_MINUTES=60
```

Замените `YOUR_PASSWORD` паролем PostgreSQL.

Секретный ключ можно сгенерировать командой:

`python -c "import secrets; print(secrets.token_hex(32))"`

Не добавляйте файл `.env` в Git.

### 3. Установка Python-зависимостей

Создайте виртуальное окружение:

`python -m venv .venv`

Активируйте его в PowerShell:

`.\.venv\Scripts\Activate.ps1`

Установите библиотеки:

`python -m pip install fastapi "uvicorn[standard]" sqlalchemy "psycopg[binary]" python-dotenv "pwdlib[argon2]" "PyJWT[crypto]"`

### 4. Создание таблиц и загрузка данных

Выполните:

`python -m backend.create_tables`

`python -m backend.seed_data`

Будут созданы таблицы и загружены 30 демонстрационных активностей.

### 5. Запуск серверной части

Из корня проекта выполните:

`python -m uvicorn backend.main:app --reload`

Адрес API: http://127.0.0.1:8000

Документация API: http://127.0.0.1:8000/docs

### 6. Запуск клиентской части

Откройте второй терминал и выполните:

`cd frontend`

`npm install`

`npm run dev`

Откройте http://localhost:5173

## Проверка основного сценария

1. Зарегистрируйте нового пользователя.
2. Войдите в систему.
3. Выберите интересующие категории.
4. Сохраните интересы.
5. Откройте персональные рекомендации.
6. Просмотрите информацию об активности.
7. Добавьте активность в избранное.
8. Проверьте её наличие во вкладке «Избранное».

## Известные ограничения

- Используется демонстрационный набор университетских активностей.
- Рекомендации формируются по совпадению категорий и интересов.
- Автоматическая загрузка мероприятий из университетских источников отсутствует.
- У части активностей не заполнены даты и ссылки на регистрацию.
- Прототип рассчитан на локальный запуск и демонстрационное использование.
- Развёртывание через Docker Compose пока не настроено.

- Контейнеризация подготовлена, но запуск через Docker Compose
  не проверен из-за ошибки Docker Engine.
- Рабочий способ запуска прототипа — локальный,
  с использованием Python, Vite и PostgreSQL.

## Автоматическое тестирование

Для проверки серверной части используется pytest.

Перед запуском тестов необходимо создать отдельную базу
uniguide_test_db и настроить подключение в файле .env.test.

Команда запуска:

python -m pytest tests/ -v

Результат последней проверки: 6 тестов пройдены успешно,
ошибок нет, 1 предупреждение о совместимости библиотек.
